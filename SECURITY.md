# Security Policy

## Supported versions

Security fixes are provided for the latest stable release of CMDBuild.
Older releases are fixed only when agreed with the maintainer.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately, using one of these channels:

* GitHub "Report a vulnerability" (Security tab of this repository)
* e-mail to cybersecurity@pat.eu

Please include the affected version, a description of the problem, the steps
to reproduce it and, if possible, a proposed fix.

You will receive an acknowledgement of the report. The maintainer will then
evaluate the problem, prepare a fix and agree with you on the disclosure date.

Information about the application security model is in the technical manual:
https://www.cmdbuild.org/en/documentation/manuals/technical-manual
